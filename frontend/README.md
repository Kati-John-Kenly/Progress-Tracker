# Progress Tracker

Progress Tracker is a local-first productivity and finance app. It does not require an account or sign-in. Routines, finance records, preferences, and AI conversations are stored in the browser on the current device.

Use **Settings → Storage & Data** to download a backup and restore it on another device. Keep backup files somewhere private.

## Run locally

```powershell
cd frontend
npm install
npm run dev
```

The app is built as a Progressive Web App. Open **Settings → App & Updates** to install it on a supported device or check for and apply updates. Installed launches request immersive fullscreen; opening the website in a browser tab continues to show the browser controls.
